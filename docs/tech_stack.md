# Стек технологий и команды проекта

Этот документ описывает основные библиотеки, используемые в проекте, и доступные команды для разработки.

## 📚 Стек технологий

### Основной фреймворк

- **Next.js 16.1.0** - React-фреймворк для продакшена.
- **React 19.2.3** - Библиотека для создания пользовательских интерфейсов.
- **TypeScript 5** - Язык программирования, строго типизированное надмножество JavaScript.

### Стилизация

- **Tailwind CSS 4** - CSS-фреймворк.
- **CSS Modules** - Используются для изоляции стилей компонентов (файлы `*.module.css`).

### Управление состоянием

- **Redux Toolkit (^2.11.2)** - Инструментарий для эффективной разработки Redux.
- **React Redux (^9.2.0)** - Официальная библиотека для привязки React к Redux.

### Компоненты и UI

- **React Icons (^5.5.0)** - Популярные иконки в виде React-компонентов.
- **Swiper (^12.0.3)** - Библиотека для создания слайдеров/каруселей.

### Разработка и тестирование компонентов (Storybook)

- **Storybook 10.1.10** - Инструмент для разработки UI-компонентов в изоляции.
- **@storybook/nextjs-vite** - Интеграция Storybook с Next.js и Vite.
- **Vite (^7.3.0)** - Инструмент сборки (используется Storybook).
- **Vitest (^4.0.16)** - Фреймворк для тестирования.

## 🚀 Команды (Scripts)

Ниже приведен список команд, которые можно запускать из терминала:

| Команда                   | Описание                                                        |
| :------------------------ | :-------------------------------------------------------------- |
| `npm run dev`             | Запуск сервера разработки Next.js (локальный просмотр сайта).   |
| `npm run build`           | Сборка приложения для продакшена.                               |
| `npm run start`           | Запуск собранного приложения (требуется предварительный build). |
| `npm run lint`            | Проверка кода с помощью ESLint.                                 |
| `npm run storybook`       | Запуск Storybook для разработки и просмотра компонентов.        |
| `npm run build-storybook` | Сборка статической версии Storybook.                            |

---

> [!NOTE]
> Все зависимости можно найти в файле `package.json` в корне проекта.
