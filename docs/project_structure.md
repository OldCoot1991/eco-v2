# Структура проекта

Этот документ описывает как организован проект и где находятся основные файлы.

## 📂 Общая структура

```
eco-v2/
├── .storybook/          # Конфигурация Storybook
├── docs/                # Документация проекта
├── public/              # Статические файлы (изображения, шрифты)
├── src/                 # Исходный код приложения
│   ├── app/             # Страницы и роутинг Next.js (App Router)
│   ├── components/      # React компоненты
│   ├── lib/             # Утилиты, хуки, Redux store
│   └── stories/         # Файлы историй Storybook (здесь лежат тесты компонентов)
│       ├── UI/          # Базовые элементы
│       ├── Components/  # Составные компоненты
│       ├── Widgets/     # Крупные блоки
│       └── Pages/       # Страницы
├── package.json         # Зависимости и скрипты
└── ...
```

## 🧩 Структура компонентов (`src/components`)

Компоненты разделены по функциональным областям или страницам:

- **ui/** - Переиспользуемые базовые элементы UI (кнопки, инпуты, модалки).
- **navbar/** - Компоненты навигационной панели.
- **footer/** - Компоненты подвала сайта.
- **home/** - Компоненты для главной страницы.
- **business/** - Компоненты для раздела "Бизнесу".
- **company/** - Компоненты для раздела "О компании".
- **...** - Другие специфичные папки (tariffs, vacancies, documents и т.д.).

## 📚 Структура Storybook (`src/stories`)

Мы организуем истории в четыре основные категории для удобства навигации в Storybook:

### 1. UI (Атомы/Молекулы)

Базовые, независимые элементы дизайна.

- В этой папке будут лежать истории для компонентов из `src/components/ui`.
- _Примеры:_ Кнопки, Заголовки, Селекты, Логотипы.

### 2. Components (Компоненты)

Более сложные элементы, часто с собственной логикой.

- _Примеры:_ Переключатель темы, Кнопки меню, Формы.

### 3. Widgets (Виджеты)

Крупные самостоятельные блоки интерфейса или целые секции страниц.

- _Примеры:_ Хедер (Navbar), Футер, Секция "Промо приложения", Таблицы тарифов.

### 4. Pages (Страницы)

Истории, демонстрирующие целые страницы или их ключевые части в сборе.

- _Примеры:_ Главная страница целиком, Страница тарифов.
